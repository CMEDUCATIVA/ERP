1. **SYSTEM-INDEX contaminado con el módulo PDF** (props del visor PDF, flujos de
   `documents/upload`, Documents hub). → **Reescrito solo-DWG**.
2. **API incompleta**: faltaba `GET /drawings/{id}/download/`. → **Añadido** (total 23).
3. **Sin catálogo de botones** (el framework PDF sí lo tenía). → **Creado**
   `docs/ui/buttons/dwg-takeoff.md`.
4. **metadata** desactualizada (22 endpoints, workspace `SKILL/`). → **Corregida**.
