# Proyecto — contexto del módulo PDF Takeoff

Forma parte de **OpenConstructionERP / ERP-DEEP**, ERP open-source de construcción,
personalizado por **CMPROYECTOS BIM** al estándar peruano CAPECO. El módulo PDF Takeoff
("Mediciones PDF") cubre la cubicación sobre planos PDF y alimenta el 5D (costo) ligando
mediciones ↔ BOQ.

- **Usuarios**: estimadores, presupuestistas, BIM/arquitectos.
- **Por qué existe**: medir cantidades sin CAD, directo sobre el PDF; conectar con el
  presupuesto.
- **Encaje**: aguas arriba de BOQ/Costos; comparte el flujo CAD-data con el módulo CAD/BIM.
- **Login demo**: demo@openconstructionerp.com / DemoPass1234!
- **Arrancar**: backend `openconstructionerp serve --port 8000`; frontend `npm run dev`
  (http://127.0.0.1:5173).
